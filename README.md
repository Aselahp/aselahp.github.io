# Asela Hevapathige, personal website

A static academic website. No build step is required. Upload the contents of this folder to the root of a GitHub Pages repository (`YOUR_USERNAME.github.io`), then enable Pages from the `main` branch under Settings, Pages.

Pages: `index.html` (About), `research.html`, `publications.html`, `experience.html`, `teaching.html`, `service.html`, `contact.html`, `404.html`. Styling is in `style.css` and the photograph is `profile.jpg`.

The files `education.html`, `industry.html`, `awards.html` and `research-experience.html` only redirect to `experience.html`, so that any old links keep working.
